    Everything raised on v1, applied:

    • Proportional is the default, not anchored.
    • A drag no longer changes the anchor — it moves within the one you picked, and only the pad changes it. The magnet that remains pulls an offset to zero.
    • Font stroke weight is back; it should never have gone.
    • The panel is draggable by its header, anywhere in the working area — it is no longer trapped inside the picture.
    • Privacy masks are items too, in the same list and selected the same way. That hole was mine, not reported.
    • Several logos, no artificial size cap, and the region and memory cost shown beside the item row.
