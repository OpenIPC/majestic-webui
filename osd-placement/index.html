Overlay — anchor and offset, back in the visual editor

Interactive mockups for OpenIPC/majestic-webui#340. Nothing here is built yet — the point is to agree the shape before any of it reaches the source. Each round of feedback gets its own version so they stay comparable.

  • v3 — the current proposal

    Second round of feedback applied:

    • The panel drags over the settings rail too, not just the working column — that rail is dead space while you are placing an overlay.
    • Nothing carries a stored name. A text overlay is the line it prints, a logo is its file, a mask is its number. No “New …”, no “… copy”, nothing to type and nothing to keep unique — which is the concept that was the argument against a layers rail in the first place.

  • v2 — the first round of feedback

    • Proportional is the default, not anchored.
    • A drag no longer changes the anchor — only the pad does. The magnet that remains pulls an offset to zero.
    • Font stroke weight restored.
    • The panel became draggable.
    • Privacy masks became items in the same list.
    • Several logos, no artificial size cap, region and memory cost shown.
